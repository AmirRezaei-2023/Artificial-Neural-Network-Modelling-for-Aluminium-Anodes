# 🤖 Artificial Neural Network Modelling of Aluminium Sacrificial Anodes

**Supplementary materials for a published research article on AI-driven prediction of sacrificial anode current efficiency.**

## 📌 Overview

This repository accompanies my published research on applying **Artificial Neural Networks (ANNs)** to predict the current efficiency of aluminium sacrificial anodes used in marine cathodic protection systems.

The study explores how electrochemical conditions, anode composition, and system parameters can be used as input features to predict anode current efficiency, demonstrating the potential of machine learning for corrosion engineering and cathodic protection design.

## 🧠 Model & Input Parameters

The ANN model considers parameters including:

- Chemical composition of the sacrificial anode
- pH and dissolved oxygen concentration
- Temperature and pressure
- Current density
- Cathode electrode characteristics
- Cathode-to-anode surface area ratio

**Target variable:** Current efficiency of aluminium sacrificial anodes.

## 📊 Key Results

The reported Mean Absolute Percentage Error (MAPE) was:

- **Training:** 6.4%
- **Validation:** 7.8%

These results demonstrate the potential of ANN modelling for predicting sacrificial anode performance under varying environmental and operating conditions.
